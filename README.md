# EnvisionStudio – Project Management Dashboard

A full-stack project management dashboard built with React, Node.js, Express, MongoDB, and Tailwind CSS.

## Overview
- **Client**: React (Vite), React Router, TanStack Query, Axios, react-hot-toast, Tailwind CSS
- **Server**: Node.js, Express, MongoDB (Mongoose), Zod
- **Testing**: Vitest, Supertest, mongodb-memory-server
